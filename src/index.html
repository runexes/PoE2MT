First launch

Choose the start date before the log file

Client.txt can grow for weeks and become very large. The start date tells the tracker where your useful history begins, so it can search backward from the end of the log and skip old sessions.

  1. Pick a date Use the first day you want to count in the tracker.
  2. Open Client.txt Use Open Client.txt first for realtime updates.
    If Windows blocks the log as a system file, use Open once instead.
  3. Keep this page open Realtime mode will add new areas while you play.

Where to find Client.txt

  • Windows:
    • Steam: C:\Program Files (x86)\Steam\steamapps\common\Path of Exile 2\logs\Client.txt
    • If Steam is installed on another drive or library folder, open that Steam library and look for: steamapps\common\Path of Exile 2\logs\Client.txt
    • Epic Games: C:\Program Files (x86)\Epic Games\Path of Exile 2\logs\Client.txt
  • macOS (CrossOver): ~/Library/Application Support/CrossOver/Bottles/<bottle_name>/drive_c/Program Files (x86)/Steam/steamapps/common/Path of Exile 2/logs/Client.txt
  • Steam Deck / Linux (Proton): ~/.steam/steam/steamapps/compatdata/<SteamAppID>/pfx/drive_c/users/<username>/AppData/LocalLow/Grinding Gear Games/Path of Exile 2/logs/Client.txt
